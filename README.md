### 🚀 About the Project
This project was developed to integrate and explore the functionalities of the **Spotify API**, utilizing development best practices within the Java ecosystem.

### 🛠️ Technologies Used
* **Language:** Java 21
* **Framework:** Spring Boot 4.0.6 (Web, DevTools)[cite: 3]
* **API:** [Spotify Web API Java](https://github.com/thelinmichael/spotify-web-api-java)[cite: 3]
* **Dependency Manager:** Maven[cite: 3]
* **Productivity:** Lombok[cite: 3]
